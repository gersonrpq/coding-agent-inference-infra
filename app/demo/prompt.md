Create a small todo list web app in the current directory, with no dependencies and no build step.

Files: `index.html`, `style.css`, `app.js`, and a `README.md` that says how to open it.

Features:
- Add a task with the Enter key or an Add button; ignore empty text.
- Mark a task done or not done with a checkbox; done tasks look crossed out.
- Edit a task's text by double-clicking it (Enter saves, Escape cancels).
- Delete a task with a button.
- Filters: All, Active, Completed, and a counter of how many tasks are left.
- A "Clear completed" button.
- Persist everything in `localStorage`, so a reload keeps the list.

Keep the code readable: small functions, no frameworks. When you are done, list the files you created.
